# Section 02 - Language Fundamentals

This section introduces MATLAB's basic language rules: variables, expressions, data types, conversions, logical values, and text.

## What You Will Learn

By the end of this section, you should be able to:

- Create and update variables
- Choose valid variable names
- Write mathematical expressions
- Understand operator precedence
- Inspect variable classes
- Use MATLAB numeric types
- Convert between numeric types
- Understand integer range and saturation
- Work with logical values
- Distinguish strings from character vectors
- Recognize other important MATLAB container types
