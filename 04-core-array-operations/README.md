# Section 04 - Core Array Operations

This section focuses on frequently used functions for inspecting, summarizing, sorting, locating, and generating array data.

## What You Will Learn

By the end of this section, you should be able to:

- Determine array dimensions and element counts
- Understand `size`, `length`, and `numel`
- Compute minima, maxima, sums, and means
- Understand dimension-based operations
- Locate extrema
- Sort array data
- Generate uniform random values
- Generate normally distributed random values
- Make random experiments reproducible
