# Section 03 - Arrays and Matrices

Arrays are central to MATLAB. Most MATLAB code becomes much easier once you are comfortable creating, indexing, reshaping, and operating on arrays.

## What You Will Learn

By the end of this section, you should be able to:

- Create row and column vectors
- Create matrices
- Concatenate arrays
- Use MATLAB's 1-based indexing
- Extract rows, columns, and submatrices
- Use the colon operator
- Use `end`
- Use logical indexing
- Understand linear indexing
- Create common arrays
- Reshape arrays
- Distinguish matrix and element-wise operators
- Create multidimensional arrays
- Understand vectorization
- Preallocate arrays efficiently
