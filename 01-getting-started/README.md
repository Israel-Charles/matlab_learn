# Section 01 - Getting Started

This section introduces the MATLAB working environment and the basic workflow used to write, run, inspect, and debug code.

## What You Will Learn

By the end of this section, you should be able to:

- Identify the main parts of the MATLAB desktop
- Execute commands interactively
- Inspect variables in the Workspace
- Create and run `.m` scripts
- Use comments and code sections
- Suppress unwanted command output
- Use breakpoints and step through code
- Understand the Current Folder
- Understand the MATLAB search path
- Use built-in help and documentation

## Prerequisites

None.

1. [MATLAB Desktop](01-matlab-desktop.md)

3. [Scripts, Editor, and Debugging](03-scripts-editor-and-debugging.md)

## Why This Section Matters

MATLAB is more than a programming language. The desktop, Workspace, Editor, Command Window, debugger, documentation, and search path are all part of the development workflow.

Understanding these tools early makes later programming substantially easier.
